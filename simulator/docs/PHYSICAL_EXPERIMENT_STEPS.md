### В симуляторе
1. Открыть симулятор: `http://localhost:8000/`.
2. Фаза 1 / Описание сцены:
   - Длина трека миссии: `4.04` м.
   - Макс. ширина полосы: `1.20` м, если физическая разметка не задана иначе.
   - Старт X/Y: `0`, `0`.
   - Покрытия: ковер (`carpet`) / гладкий под (`smooth_floor`) / линолеум (`linoleum`) согласно натурному опыту.
   - Для ковролина PWM 10000: `friction=0.70`, `rolling=0.03`, `speed_scale=1.0`, `accel_scale=0.85`, `energy_scale=1.15` -- проверить корректность
3. Фаза 1 / Описание строя:
   - Строй: `line`.
   - N агентов: `1`.
   - Шаг: `0.38` м (значение по умолчанию).
   - Нажать `Загрузить` (?), затем `Применить строй`.
4. Фаза 1 / Агенты:
   - Открыть `r01`.
   - Имя: `tank01`.
   - Длина: `0.245` м.
   - Ширина: `0.230` м.
   - max speed для ковролина PWM 10000: `0.9395` м/с (`4.04 / 4.3`).
   - max power: `20000` (в JSON агента).
   - tank PWM: min `4000`, step `1000`, period `20000` (???).
   - (Проверить, не критично)Выбрать цвет для идентификации агента; хвост будет того же цвета.
   - Нажать `Применить`.
5. Фаза 2 / Модель:
   - Алгоритм: `smooth_adaptive_clusters` или `completion_astar`.
   - Целевая функция: `finish_first`.
   - Восприятие: `local` (непонятно) для отладки `global`.
   - Общая память: `false`, при N=1 она ни на что не влияет.
   - Нажать `Применить модель`.
6. Фаза 3 / Запуск симуляции:
   - `dt = 0.20` с.
   - `max steps = 250`.
   - (кажется, что избыточно перед созданием) Нажать `Применить`.
   - Нажать `Создать / пересоздать`, затем `До финиша` (точно не Auto?).
7. Фаза 5 / Анализ:
   - Скачать `log.csv` — полный измерительный и контрольный лог.
   - Скачать `g.log` — полный g-like лог прохождения -- как в танке.
   - Скачать `cmd.log`приближённая последовательность key/protocol для `tank.c` -- надо проверять.
